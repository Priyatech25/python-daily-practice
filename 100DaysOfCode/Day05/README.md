\# Day 5 - Recursion Basics



\## Topics Covered

\- Recursive functions

\- Base condition

\- Function call stack

\- Factorial

\- Fibonacci series



\## Problem

Solve problems by calling a function within itself.



\## Approach



\### Factorial

n! = n × (n-1)!



\### Fibonacci

F(n) = F(n-1) + F(n-2)



\## Time Complexity

\- Factorial → O(n)

\- Fibonacci (recursive) → O(2^n)



\## Space Complexity

\- O(n) due to recursion stack



\## What I Learned

Recursion helps solve divide-and-conquer problems and tree/graph traversal problems.
