\# Day 4 - Sorting Algorithms



\## Topics Covered

\- Bubble Sort

\- Selection Sort

\- Nested loops

\- Swapping elements

\- Finding minimum element



\## Problem

Sort an unsorted array in ascending order.



\## Approach



\### Bubble Sort

Compare adjacent elements and swap if they are in wrong order.



\### Selection Sort

Find the minimum element and place it at correct position.



\## Time Complexity

\- Bubble Sort → O(n²)

\- Selection Sort → O(n²)



\## Space Complexity

\- O(1)



\## What I Learned

Sorting is a fundamental concept used in searching, optimization, and data organization.
