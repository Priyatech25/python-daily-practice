\# Day 3 - Searching Algorithms



\## Topics Covered

\- Linear Search

\- Binary Search

\- Looping

\- Condition Checking

\- Mid calculation



\## Problem

Find a target element in a list efficiently.



\## Approach



\### Linear Search

Check each element one by one until target is found.



\### Binary Search

1\. Works on sorted arrays

2\. Find middle element

3\. Compare target with middle

4\. Search left or right half



\## Time Complexity

\- Linear Search → O(n)

\- Binary Search → O(log n)



\## What I Learned

Binary Search is much faster than Linear Search for sorted data.
