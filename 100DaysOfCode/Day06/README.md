\# Day 6 - Stack Basics



\## Topics Covered

\- Stack

\- Push

\- Pop

\- Peek

\- Empty check

\- Reverse string using stack



\## Problem

Understand LIFO (Last In First Out) data structure.



\## Approach

Implemented stack using Python list:

\- append() → Push

\- pop() → Pop

\- stack\[-1] → Peek



Applied stack concept to reverse a string.



\## Time Complexity

\- Push → O(1)

\- Pop → O(1)

\- Peek → O(1)



\## Space Complexity

\- O(n)



\## What I Learned

Stack is used in:

\- Undo/Redo

\- Function calls

\- Expression evaluation

\- DFS traversal
